# End-to-End-E-Commerce-Analytics-Platform
End-to-end event-driven e-commerce data platform using Kafka, Spark, Airflow, and a medallion lakehouse architecture.

## Problem Statement
A UK-based online retail company generates millions of transactional events across orders, products, and customers. Business teams require near real-time visibility into sales performance, customer behavior, and cancellations across regions. However, raw transactional data arrives at high volume, contains cancellations and duplicates, and is not analytics-ready.

This project builds an end-to-end event-driven data platform that ingests retail transaction events in real time, processes them through a medallion lakehouse architecture, and delivers clean, analytics-ready datasets to a data warehouse and dashboards.
